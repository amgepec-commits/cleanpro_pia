1. HISTORIAS DE USUARIO (USERSTORIES)
ID Rol User Story
US-01 Cliente Como cliente, quiero solicitar una cotización indicando la
ubicación, superficie, tipo de inmueble, frecuencia y
servicios adicionales, para conocer el precio del servicio.
US-02 Coordinador Como coordinador, quiero calcular la duración estimada
de una limpieza según los metros cuadrados y servicios
adicionales, para programar correctamente el servicio.
US-03 Coordinador Como coordinador, quiero determinar la cantidad de
personal necesaria según el tamaño del inmueble, para
asignar una cuadrilla adecuada al servicio.
US-04 Coordinador Como coordinador, quiero registrar y programar un
servicio aceptado por el cliente, para organizar su
realización.
US-05 Coordinador Como coordinador, quiero consultar la agenda de
servicios y la disponibilidad del personal, para asignar
una cuadrilla adecuada.
US-06 Coordinador Como coordinador, quiero recibir una sugerencia de la
cuadrilla disponible más cercana, para reducir el tiempo y
esfuerzo de las asignaciones manuales.
US-07 Supervisor Como supervisor, quiero registrar la hora de llegada y
salida de la cuadrilla, para mantener evidencia del
tiempo trabajado.
US-08 Supervisor Como supervisor, quiero registrar el checklist de las áreas
terminadas, para dejar evidencia de las actividades
realizadas.
Reporte
US-09 Cliente Como cliente, quiero firmar la conformidad del servicio al
finalizar la limpieza, para confirmar que el trabajo fue
realizado.
US-10 Supervisor Como supervisor, quiero registrar daños, accidentes o
quejas mediante fotografías, para documentar las
incidencias ocurridas durante el servicio.
US-11 Coordinador Como coordinador, quiero recibir las incidencias
registradas por el supervisor, para poder gestionar la
solución correspondiente con el cliente.
US-12 Coordinador Como coordinador, quiero registrar en tiempo real los
cambios de personal en un servicio, para que
Administración reciba la información oportunamente
para el control de nómina.
US-13 Supervisor Como supervisor, quiero solicitar la cotización de un
servicio adicional al coordinador cuando el cliente lo
solicite en el lugar, para obtener la autorización del
nuevo costo antes de realizarlo.
US-14 Coordinador Como coordinador, quiero recalcular el precio cuando el
inmueble sea mayor al reportado inicialmente, para
cobrar un importe acorde con el trabajo requerido.
US-15 Coordinador Como coordinador, quiero registrar una reprogramación
solicitada por el cliente, para aplicar correctamente las
condiciones y penalizaciones correspondientes.

Conclusiones
Con la especificación de estas 15 historias de usuario, se consolida la totalidad de
las necesidades funcionales requeridas para la plataforma de CleanPro. El
desglose detallado por rol garantiza que cada flujo operativo —desde la
cotización inicial del cliente hasta el cierre de servicio con firma de conformidad
y reporte a administración— cuente con una funcionalidad asignada que guiará
las etapas de diseño, desarrollo y pruebas de la solución tecnológica.
